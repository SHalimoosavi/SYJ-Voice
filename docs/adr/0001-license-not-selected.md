# ADR 0001: Project license not selected

Status: Awaiting owner decision. Date: 2026-11-05.

AGPL-3.0-only provides network copyleft: modified network services generally must offer corresponding source to remote users. This favours reciprocity but may deter some adopters. Apache-2.0 is permissive, easier for proprietary integration and includes express patent licensing, but hosted modifications need not be published.

Decision: no license selected. Do not create LICENSE or claim repository is licensed. Third-party licenses remain separate. Obtain legal review before release.
