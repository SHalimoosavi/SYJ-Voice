# Roadmap

## Phase 0 — Foundation
Monorepo, architecture, secure local development, API persistence/auth foundation, web shell, telephony config, CI and tests.

## Phase 1 — App-to-app
Authenticated browser-to-browser WebRTC audio, production TURN/STUN, device testing, call telemetry; then browser-to-SIP via Asterisk, SIP provisioning, DTMF, hang-up and CDR ingestion.

## Phase 2 — PSTN and sponsorship
Vendor-neutral SIP trunk adapters, authorised carrier onboarding, country routing, sponsorship ledger, reservations and reconciliation. PSTN remains disabled without approved carrier, compliance and funding.

## Phase 3 — Mobile
Improve installable PWA and mobile browser reliability; evaluate native clients only after web flows stabilise.

## Phase 4 — Scale
SIP proxy/SBC, horizontal scaling, observability, disaster recovery, capacity/fraud testing and federation review.

Release gates require reproducible tests and evidence. Public PSTN additionally requires jurisdiction-specific legal review and authorised carrier connectivity.
