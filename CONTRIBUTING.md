# Contributing

Discuss significant changes in an issue. Create focused branches; never push directly to main. Include tests and docs. Run backend lint/type/tests and frontend type/build before PR. Never commit secrets, personal data, carrier credentials or production call records. Do not enable PSTN routes or alter production infrastructure without owner approval. Report exactly what was run and what remains unverified.

Project license is pending owner selection. Do not add a LICENSE file or claim project-wide licensing until approved.
